# 拾物公开商品资料

当前批次：2026-10-17 采集，24 件 IKEA 商品、67 条真实评价短摘录，6 个品类。每件商品有 2–4 张实际商品图片，保存在 `frontend/public/media/catalog/`，无需外部图片热链。网页原文缓存位于本目录的 `pages/`（不提交）。

`catalog.json` 保存商品来源、源货号、原页币种和价格、评分与评价总数、每张图片的原地址、短评原文与原作者。中国官网与美国官网通过公开全球货号精确匹配，共 8 件有中国官网价格；其余的本地人民币演示价按美元价 × 7 设置，商品页已明确注明。采集价不是实时售价。灯具中美国来源款式保留美规提示。

人物主页、笔记、点赞、关注、库存、地址为本地演示内容。笔记是原创编辑搭配灵感，没有虚构购买使用经历。公开评价保留原文和原作者，产品页与评论区提供原页链接，不能视作本站成交或已购验证。每个商品页面的评价摘录总量不超过 25 个英文单词；原页评价总数与展示的短摘录数量分别说明。

头像来自 Random User 的示意照片，不是原评价作者照片，也不代表真实注册用户。示意照片来源逐条记录于 `catalog.json`，站内来源页与评价区均注明这种区别。

## 重新导入

在项目根目录执行：

```bash
./scripts/seed_real_catalog.sh
```

脚本先备份整个数据库到 `.run/backups/`，停止写入进程后进行事务导入，再清理此项目的 `v1:` 缓存并恢复进程。只清理已识别的 `codexmock*`、`codexcommerce*`、`commerce_<数字>` 测试账号及其关联记录，以及上次导入的人物；其他账号保留。原来的 `llx` 账号保持不变。不要使用旧的 `seed_commerce.sh` 恢复占位数据。

体验买家：`小满同学`；店主：`阿栗的厨房`。共享演示密码：`MockPass123!`。

导入会在 `frontend/public/catalog/` 生成 ID 与来源映射及说明页。脚本把它同步到运行中的生产前端；开发服务器直接读取本地文件。

仅准备 SQL、校验素材而不写数据库：

```bash
python3 scripts/import_real_catalog.py
```

重新采集公开商品资料（需要网络）：

```bash
python3 scripts/collect_real_catalog.py
```
